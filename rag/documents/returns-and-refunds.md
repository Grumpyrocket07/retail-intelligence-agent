# Returns and Refunds

> Fictional demo document for the Retail Intelligence Platform project. Cottage Lane Gifts is not a real company.

## Return window
You can return unused items in their original packaging for a refund within 30 days of delivery. Wholesale accounts follow different return rules, which are described in the wholesale terms.

## Return postage
You pay the postage for returns if you have simply changed your mind. If an item is faulty, damaged or was sent in error, we pay the return postage. A prepaid return label can be created from your account page.

## How refunds are paid
Refunds are paid to the original payment method within 5 working days after we receive and inspect the returned items. Each return is recorded as a credit note whose number starts with the letter C, for example C581484, so that it can be matched to your account.

## Items that cannot be returned
The following cannot be returned unless they are faulty: personalised or engraved items, candles that have been lit, perishable food and drink, and gift vouchers.

## Exchanges
We do not offer direct exchanges. If you would like a different item, return the original for a refund and place a new order.
